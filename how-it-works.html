How it works

From a typed word to a globe path — what Lexicon Earth fetches, what it invents, and how to read the result.

1. Search

You enter an English word. The app asks Wiktionary for the matching page (trying common capitalizations), then looks for English etymology sections in the page wikitext.

If several etymologies exist (homographs), you can choose which sense to load. Optional multi-source mode can also query Wikidata and Kaikki.

2. Parse a lineage

Etymology templates in Wiktionary (inheritance, borrowing, derivation, and related forms) are parsed into a chain of word-forms. Each form keeps its language label, gloss when available, and epistemic status (attested, reconstructed, disputed).

Extracted prose summaries are labeled as extracted text — not quotations of scholarly consensus.

3. Place forms on the map

Languages are mapped to approximate heartlands (a point for the language’s historical or modern center). That is an association for visualization, not evidence that a specific inscription or speaker lived at that coordinate.

When a language code is missing from our table, that form may appear in the panel without a map marker. The globe bridges mapped neighbors so the journey still reads as a path.

4. Read the journey

  • Markers — one mapped form in the chain.
  • Arcs — schematic links between consecutive mapped forms.
  • Labels — word form plus origin place / civilization name when known.
  • Journey slider — reveal the path over time.
  • Panel — definition, timeline, relationship notes, and citations.

Example: Searching orange may show a chain through India, Persia, Arabia, and Western Europe. The arcs illustrate sequence in the extracted etymology — not a documented caravan route.

5. Cache & offline

Successful lookups are stored locally. A small starter set ships with the app. After the first visit, a service worker can keep the shell, map data, and libraries available offline. New words still need the network.

Limits worth knowing

  • Coverage is strongest for English entries on Wiktionary.
  • Reconstructed proto-forms are hypotheses; the UI marks them as such when possible.
  • Multi-source mode is slower and may return alternate candidate senses.
  • Always open the cited Wiktionary page for full context, footnotes, and debate.
